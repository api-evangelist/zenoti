## API Reference
- [Generate an access token](https://docs.zenoti.com/reference/generate-an-access-token.md): **Purpose**: The purpose of this API is to generate a new access token for the authentication of the user. Businesses can use this token to access Zenoti APIs.  **Note**: The access token is valid only for 24 hours, post which you must generate a new token by invoking the Refresh an access token API.
- [Refresh an access token](https://docs.zenoti.com/reference/refresh-an-access-token.md): **Purpose**: Use this API to refresh an expired access token. Since an access token is valid for 24 hours, you must use this API to generate a new access token.  ###Things to remember: * A newly generated refresh token is valid for 90 days (3 months). It will expire after this period. * A refresh token can only be used once. **Caution**: Invoking this API will deactivate the existing access tokens and generate a new access token. So use the Refresh an access token API only when an access token is about to expire or has already expired.  **Note**: Remove the hash (#) at the end, when using this API.
- [Revoke an existing access token](https://docs.zenoti.com/reference/revoke-an-existing-access-token.md): **Purpose**: At any point of time, if you want to delete the existing access tokens, you can use this API to do so. This will immediately revoke all the existing access tokens and users cannot access the Zenoti APIs.
- [Center APIs](https://docs.zenoti.com/reference/centers.md)
- [List all centers](https://docs.zenoti.com/reference/list-all-centers.md): This API retrieves a list of all centers of an organization.
- [Retrieve list of centers close to the base center](https://docs.zenoti.com/reference/fetch-list-of-centers-based-on-parameters.md): This API retrieves a list of centers based on the base center's ID and coordinates (latitude and longitude).
- [Retrieve a center](https://docs.zenoti.com/reference/retrieve-a-center.md): This API helps you to retrieve the details of a center. You must specify the unique identifier of the center as `center_id`.
- [Retrieve Services for the Requested Center](https://docs.zenoti.com/reference/retrieve-campaignintro-pricing-along-with-services.md): This API fetches services from the requested center. Based on certain query parameters like campaign_id and campaign_code, you can get additional information such as campaign-based discounted price information of the services.
- [Deactivate or disable a center](https://docs.zenoti.com/reference/deactivate-or-disable-a-center.md): This API will deactivate a center in an organization.
- [List all categories](https://docs.zenoti.com/reference/list-all-categories.md): This API helps you to retrieve the list of categories that are active in a center. You must specify the unique identifier of the location (center) in the API request as `center_id`.
- [Retrieve a category](https://docs.zenoti.com/reference/retrieve-a-category.md): This API helps you to retrieve the details of a category.  You must specify the unique identifier of the location (center) as `center_id` and the unique identifier of the category as `category_id` in the API request. The API then retrieves the details of the category.
- [List all rooms of a center](https://docs.zenoti.com/reference/list-all-rooms-of-a-center.md): This API helps you to retrieve all the rooms that are active in the center.  You must specify the unique identifier of the center as `center_id` in the API request. You can also leverage the pagination feature by passing `page` and `size` query parameters if you have a large number of records to be displayed. By default, `page` is set as 1 and `size` is set as 10. `size` cannot be more than 100: which means that the maximum records per page cannot be more than 100.
- [Retrieve a room of a center](https://docs.zenoti.com/reference/retrieve-a-room-of-a-center.md): This API helps you to retrieve the details of a specific room at the required center.  You must specify in the API request the unique identifier of the location (center) as `center_id` and the unique identifier of the room as `room_id`. The API then retrieves the details of the room.
- [List all employees of a center](https://docs.zenoti.com/reference/list-all-employees-of-a-center.md): This API helps you to retrieve all the employees that are active in the center on the specified date.  You must specify the unique identifier of the center as `center_id` in the API request. You can also leverage the pagination feature by passing `page` and `size` query parameters if you have a large number of records to be displayed. By default, `page` is set as 1 and `size` is set as 10. `size` cannot be more than 100: which means that the maximum records per page cannot be more than 100.
- [List all therapists of a center](https://docs.zenoti.com/reference/list-all-therapists-of-a-center.md): This API helps you to retrieve all the therapists that are active in the center on the specified date. You must specify the unique identifier of the center as `center_id` in the API request.
- [List all blockout times of a center](https://docs.zenoti.com/reference/list-all-blockout-times-of-a-center.md): Retrives the list of Blockout times created between the start date and end date of the center whose ID is passed as {center_id} and block out times of all the rooms or employees who had a block out time created in the appointment book for that center.
- [Center attendance for a date](https://docs.zenoti.com/reference/center-attendance-for-a-date.md): This API retrieves the attendance of all the employees at a center on the specified date.  You must specify the unique identifier of the center as `CenterId` and the required date as `Date` in the API request.
- [Retrieve the schedules of employees of a center](https://docs.zenoti.com/reference/retrieve-the-schedules-of-employees-of-a-center.md): This API helps you to retrieve the schedules of employees of the specified center. You must provide the unique identifier of the center as `center_id`. You must also specify the appropriate `start_date` and `end_date` values for which you want to view the schedules of employees.  **Note**: To run this request, you must enable the **Schedule** role permission. This allows the user to access the employee's schedule. Navigate to the organization-level, **Security Roles** > `employee role` > **Permissions** > **Employee Manager** > **Other Settings** > **Schedule**.

You can also use the `expand` parameter in the API request to specify details for the `additional_info`, `catalog_info`, `category_id`, `variants_info`, `add_ons_info`, and `image_paths` parameters. The `category_id` parameter enables you to filter services according to their respective category or sub-category.  In addition, you can leverage the pagination feature by passing `page` and `size` query parameters if you have a large number of records. By default, `page` is set as 1 and `size` is set as 10. Size cannot be more than 100: which means that the maximum records per page cannot be more than 100.

The API then retrieves the details of the service.You can also use the `expand` parameter in the API request to specify details for the `additional_info`, `catalog_info`, `variants_info`, `add_ons_info`, `tags`, and `image_paths` parameters.

- [Validate NPI details of a prescriber](https://docs.zenoti.com/reference/validate-npi-details-of-a-prescriber.md): This API will validate the NPI number of prescribers before initiating onboarding to ePrescribe.
- [Retrieve compliance statistics](https://docs.zenoti.com/reference/retrieve-compliance-statistics.md): This API retrieves all compliance statistics of an organization.
- [Get guest consent for ZenScribe](https://docs.zenoti.com/reference/get-the-guest-consent-for-zenscribe.md): This API fetches guest consent.
- [Add guest consent for ZenScribe](https://docs.zenoti.com/reference/add-the-guest-consent-for-zenscribe.md): This API adds the guest consent for owner ID.
- [Get Guest Form Details](https://docs.zenoti.com/reference/get-guest-form-details.md): This API retrieves guest form details for a given guest.
- [Update Guest EMR Data](https://docs.zenoti.com/reference/update-guest-emr-data.md): This API adds or updates multiple EMR data sections for a guest in a single API call. Supports allergies, medications, medical histories, social history, and vitals — each section is optional and processed independently in parallel, with per-section error reporting.
- [Retrieve open invoices](https://docs.zenoti.com/reference/retrieve-open-invoices.md): This API searches invoices by invoice number or guest user ID, or retrieves all open invoices for a given date.
- [Lock Invoice](https://docs.zenoti.com/reference/lock-invoice.md): This API locks an invoice to prevent any further edits or modifications after the invoice receipt has been printed or emailed.  Once an invoice is locked, invoice items or details cannot be modified.
- [Update Group Invoice Properties](https://docs.zenoti.com/reference/update-group-invoice-properties.md): This API updates specific properties of a group invoice — either its name or notes — using the group invoice ID. It accepts a property type (0 for name, 1 for notes) and a new value, and optionally an employee ID to record who made the change when the request is made using an API key.
- [Delete Membership Advanced Booking Rule](https://docs.zenoti.com/reference/delete-membership-advanced-booking-rule.md): This API soft-deletes a single membership advance booking rule by its rule_id, setting Void = 1 in tblMembershipAdvancedBookingRules. Triggered by the delete icon   on each row in the "Previously Added Rules" table on the Advance Booking Windows admin settings page.
- [Create Membership Advanced Booking Rules](https://docs.zenoti.com/reference/create-membership-advanced-booking-rules.md): This API Creates one or more membership advance booking rules for the organization. Each rule maps a membership to a specific class or amenity with a configured number of days in advance that the member can book. When multiple item_ids are supplied, one DB row is created per item_id in a single request.
- [Get all Membership Advanced Booking Rules](https://docs.zenoti.com/reference/get-all-membership-advanced-booking-rules.md): This API returns the full list of membership-based advance booking rules configured for the organization. Used by the "Advance Booking Windows" admin settings page to populate the "Previously Added Rules" table.
